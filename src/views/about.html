Acerca del proyecto

FranquiciaChat es una prueba de concepto (POC) desarrollada por ComicSansCon, una agencia digital especializada en experiencias interactivas para fans de videojuegos, películas y series.

El objetivo es demostrar cómo integrar un modelo de lenguaje (Google Gemini) para crear conversaciones creíbles con personajes ficticios, manteniendo la API key segura del lado del servidor mediante Vercel Functions.

Stack técnico

  • HTML5, CSS3 (mobile-first, Flexbox/Grid) y JavaScript vanilla
  • Axios para las peticiones HTTP
  • Routing propio con la History API (sin frameworks)
  • Vercel Serverless Functions como backend seguro
  • Google Gemini API para la generación de respuestas
  • Vitest para tests unitarios

Personajes de esta POC

El historial de cada conversación se guarda en localStorage de tu navegador — nunca se envía a ningún lado más que a nuestro propio servidor al chatear.
